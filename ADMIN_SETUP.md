# Настройка админки БИОПЛИТ

## 1. Применить базу данных
1. Откройте проект Supabase `bioplit`.
2. Перейдите в **SQL Editor → New query**.
3. Скопируйте целиком файл `supabase/migrations/202611110001_admin_cms.sql`, нажмите **Run**.
4. Убедитесь, что запрос завершился без ошибок.

## 2. Создать первого администратора
1. В Supabase откройте **Authentication → Users → Add user → Create new user**.
2. Укажите почту владельца проекта и задайте пароль. Для первого входа используйте адрес, который контролирует владелец сайта.
3. Скопируйте UUID созданного пользователя (не пароль).
4. Откройте **SQL Editor** и выполните, заменив UUID на скопированный:
   ```sql
   insert into public.admin_users (user_id)
   values ('ВСТАВЬТЕ-UUID-ПОЛЬЗОВАТЕЛЯ')
   on conflict (user_id) do nothing;
   ```
5. Включите подтверждение почты в Authentication → Providers → Email, если оно требуется вашей политикой безопасности. Не включайте публичную регистрацию ради админки.

## 3. Вход
Откройте `https://bioplit.vercel.app/admin` и войдите созданной учётной записью.

## 4. Передать доступ клиенту позже
Создайте отдельного пользователя в Authentication → Users и добавьте его UUID в `admin_users` тем же SQL-запросом. Для отзыва доступа удалите только его строку из `admin_users`; пользователя можно оставить или удалить отдельно.

## Разделы панели
- Каталог: названия, описания, изображения, цены и порядок карточек.
- Наши работы: фото, описание, категория, год, место, ссылка на видео.
- Услуги: название, описание, стоимость и единица измерения.
- Прайс-лист: позиции и стоимость за м², погонный метр или штуку.
- Настройки сайта: текстовые значения и контактные данные.

Изображения загружаются в публичный bucket `site-media` (публичный только на чтение); загрузка, изменение и удаление разрешены только администраторам.

## Важно
- Публичной формы регистрации в интерфейсе нет.
- Не публикуйте secret/service_role key. В браузере используется только publishable/anon key.
- SQL-миграция создаёт структуру и политики, но не копирует автоматически существующие статические карточки из React-кода в таблицы. До переноса данных сайт продолжает отображать прежнее содержимое.
